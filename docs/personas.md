# 人格与模板管理

## 使用

在「人格与节奏」顶部下拉选择人格或模板，修改下方人设、接话节奏和会话保留设置，然后点击“保存设置”启用。切换不会更换模型账号，也不会断开已经连接的 QQ。

- **新建**：打开表单，由用户填写名称、类型，选择空白人设或复制当前设置。添加到列表后仍需保存。
- **另存为模板**：复制当前人设与节奏，供之后选择；不自动切换，也不复制任何笔记或对话。
- **删除**：先保存更改，点击“删除”并确认。会清理所选条目的长期笔记和短期对话；其他人格保留。删除当前启用项后自动切换到剩余人格 / 模板，QQ 不断开。最后一项保留，删除按钮会说明原因。加密 `.bak` 备份仍沿用原机制，备份需单独管理。
- **显示名称**：仅改列表名称，不更换记忆空间；叫名触发仍由下方“叫名触发”字段配置。
- **待保存切换**：选择未保存时会明确显示“保存后切换启用”。运行面板与记忆页始终标明实际已启用人格。

最多保留 16 个人格 / 模板。此版本只把原有的大肥鱼纳入列表，没有自动创建新角色、预置多个人设或额外模板。

## 独立记忆

每个人格 / 模板使用稳定 ID，长期笔记、短期对话、运行记录按人格隔离。返回原人格后，恢复它自己的记忆；更改显示名称不会创建另一份记忆。

复制设置时不复制记忆；在一个人格中 `/reset`、说“忘记我”、删除笔记或关闭短期记录，不影响其他人格的数据。历史轮数和有效期也按人格分别保存。已有的群聊、成员及渠道隔离继续生效。

默认人格保留原来的会话标识，旧版加密笔记和短期历史直接沿用；新增条目使用独立的 `persona:<id>:` 会话命名空间。所有内容继续加密写入本机 `state.enc`，浏览器公开配置只包含人格设置，不包含对话正文。

人格切换会取消旧人格还未送达的回复，旧请求不会跑到新角色的聊天中。界面也会清理上一人格的临时聊天显示，记忆列表按当前已启用人格重新加载。

## 验证

`npm run check` 运行构建及全部测试。`standalone/test/personas.test.mjs` 在临时目录中验证：旧加密数据迁移、人格与节奏切换、长短期记忆隔离、模板不复制记忆、重置与删除不串人格、保留策略隔离、旧请求取消、草稿切换保留编辑、非法配置拒绝、重命名、HTTP 记忆接口和 QQ 连通保持。

测试创建的人格 / 模板只存在于临时夹具，不写入用户实际配置。

删除通过带版本号和明确确认标记的专用接口执行；列表过期时返回冲突，不会误删已经切换的条目。删除后的数据重新加载验证包含原始默认人格被删除、仅剩模板等情况。
