# TRAE 中国版客户端协议适配

## 完成内容

`server/trae.mjs`：本地登录回调、令牌轮换续期、实际模型列表过滤、SOLO SSE 解析、积分查询与每日签到。

`server/store.mjs`：保留兼容旧配置，TRAE 凭据放入现有 AES-GCM 密文，公开配置只含状态。浏览器上传的 `credential` 不会覆盖服务器凭据。

`server/providers.mjs`：`type: trae` 分支调用独立适配器，不要求 API Key；可继续使用现有主账号/备用模型配置。

`server/index.mjs`：同源、cookie 鉴权的 `/api/trae/login`、`cancel-login`、`logout`、`models`、`balance`、`refresh`、`checkin`。登录操作只准备厂商授权链接，不自动代用户登录。推理走原 `/api/chat`，没有发布第三方公开反代服务。

`ui/trae-account.jsx`：登录、上次余额、签到状态、自动签到开关和模型选择。

## 协议来源与限制

来自仓库的 `vendor/channel-pack/pack.js` 中 `trae-auth.ts`、`trae.ts`、`trae-adapter.ts`、`trae-credits.ts`，MIT / Copyright (c) 2026 Jet。完整许可见 `vendor/channel-pack/LICENSE`。保留实际接口形状，不复制整个宿主包。

协议快照含客户端版本 0.1.52、版本码 20260811、plugin 版本 2.3.62834；这些仅是源码里已观察的值，不是联网确认的最新版本。没有读取、提取或搬运本机其他软件的登录凭据，也没有包含管理员密钥。

授权回调仅处理快照已有的 refreshToken / userJwt.Token 形式。出现新 PKCE/code 流程会停下并报协议变化，不编造 verifier 或假装成功。接口不是官方公开 API，不推定厂商对第三方接入的授权或稳定性承诺。

## 每日签到的幂等与失败语义

1. 使用上海自然日；开关默认关闭，账号缺失或要求重新授权时不执行。
2. 并发 tick / 手动签到合并为一个任务。
3. 先检查上游 `checked_in`，已领取则记录，不调用 claim。
4. 调用 claim 之前写入当天 `claiming` 记录。
5. 成功记录 `claimed`；网络/格式/未知结果记录 `uncertain`；429/403/9074 记录 `blocked`。
6. 当天已提交领取、已领取或风控记录不自动重复领取，包含重启后未能确认的 `claiming`。状态查询阶段的网络错误为 `status-error`，15 分钟后重查；活动未启用为 `inactive`，1 小时后重查。二者不代表已经提交领取。
7. 终态次日再检查；离线不执行、不补领历史日期。取消登录/退出使用 epoch 防止旧授权操作写回。

没有设备身份轮换、风险标记规避、批量账号或注册流程。登录和推理使用安装生成的稳定设备身份；签到头部使用旧协议固定的单账号派生字段，不因错误而变化。

## 2026-10-26 授权页“网络错误”修复

已在官方授权页复现：旧版 `auth_callback_url` 使用 `/authorize/<随机值>`，但网页在请求登录状态之前用 `^http://127\.0\.0\.1:(\d+)/authorize$` 校验整个回调地址，不允许路径后缀或查询串。失败分支直接显示通用“网络错误”，不是本机 DNS/TLS 失败。

修正为准确的 `/authorize`；每次生成独立的 192-bit `login_trace_id`，官方回跳函数将其原样作为 `loginTraceID` 返回。本地验证唯一参数、会话值、Host、GET、路径和单次使用，错误请求不消耗当前会话。没有取消会话校验来迁就 URL 格式。

证据为当日公开授权页加载的 `static/js/async/authorization/page.b9f91f9896.js`：授权组件的初始化校验和 `ek` 回跳函数。未使用账号 Cookie、密码或令牌进行诊断。

修复后必须取消旧授权、重新生成链接；刷新旧厂商页面仍是旧地址。单元测试含官方 URL 正则、缺失/错误/重复追踪值和跨会话拒绝。

实机页面验证：同一浏览器、同一网络下，旧链接显示“登录失败 / 网络错误”，修正后的新链接跳转到官方 `/login?login_platform=solo&redirect_url=…`，显示手机号、验证码和其他登录选项。截图：`design/trae-auth-fixed.png`。`npm --prefix standalone run check` 构建及 25/25 测试通过；未输入手机号、验证码或完成真实账号授权，换令牌与推理仍待账号联调。
