# 大肥鱼 BigFish · 独立本地应用

面向用户的功能介绍与快速开始见 [仓库主页](../README.md)。这里记录独立版的运行和维护方式。

## 运行

Node.js ≥ 22.19；从仓库根目录执行：

```sh
npm --prefix standalone ci
npm run build
npm start
```

默认管理地址 `http://127.0.0.1:3210`。只运行独立版不需要安装根目录的旧 DSH 依赖。也可以在本目录执行 `npm ci && npm run build && npm start`。

```text
官方 QQ Bot / NapCat
          │
          ▼
本地社交决策 → 人格与近期上下文 → 显式记忆
          │
          ▼
统一模型目录 → 当前逻辑模型的可用渠道 → 模型回复
          │
          └──────────────────────→ QQ
```

## 初次配置

1. **模型账号**：从厂商下拉框选择 TRAE、CodeArts、ZCode 等账号入口。页面只展示当前选中厂商，不混用其他账号的状态。登录后获取模型目录，在上方统一模型选择器中选模型并保存。
2. **互动实验室**：先验证模型调用、人格和记忆；“模拟普通群消息”用于观察接话 / 安静决策，不会向 QQ 发消息。
3. **QQ 接入**：官方 Bot 使用手机 QQ 扫码，自动保存凭据并默认 WebSocket 直连；NapCat 使用 OneBot 11 正向 WS 和数组格式。配置对应白名单后连接。
4. **人格与节奏**：昵称、兴趣、回复概率、冷却、对话延续窗口、分钟预算和安静时间均可设置。
5. **记忆管理**：查看、删除明确交代的笔记。默认每人每群 8 条，保留 30 天；实验室和 QQ 分开，官方机器人额外按 AppID 隔离。

兼容 API 与本地模型配置保留在账号页高级区域，不是 QQ 登录协议。没有自动从旧 DSH 配置或其他软件搬运凭据。

## 模型路由

`activeModelId` 表示统一逻辑模型；底层实际调用仍使用厂商原始 ID。合并同版本日期别名，不合并不同代际、能力和预览版本。仅已登录、启用的账号参与路由。

同模型的备用渠道只在请求尚未被接受时接替；响应已被接受后出现解析或流错误，不会重复发送另一笔推理请求。可选输出 Token 上限留空时沿用服务端默认值，不再强制裁剪 6000 字符或 800 Token。

## 自动签到

支持每日签到的渠道可逐个开启。应用在线时检查上海自然日；重启补查当天，不补领历史日期。并发操作合并，领取前先保存提交状态。仅状态查询失败时按退避重查；已提交但结果不确定时不盲目重复领取。

默认关闭；本机已保存的选择不因升级或品牌改名重置。签到不是无限额度保证，可能消费账号付费权益。

## 环境变量与开发

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| `PORT` | `3210` | 本机管理端口 |
| `BIGFISH_DATA_DIR` | `standalone/data/` | 密文、密钥和应用状态目录 |

```sh
npm --prefix standalone run dev    # 监视重建前端
npm start                         # 另一个终端运行后端
npm run local:check               # 独立版构建与测试
```

修改后端后需要重启；前端监视模式重建后重载页面。`PORT` 不会改变高级 Webhook 的独立回调端口。没有原生桌面安装器，也没有公网多用户服务。

## 状态与数据

- 管理服务只监听 `127.0.0.1`，校验 Host / Origin，API 使用随机 HttpOnly SameSite 会话 cookie。
- Key、账号凭据、QQ AppSecret、OneBot Token、设置和笔记加密保存到 `state.enc`；本机密钥为 `local.key`，文件权限 0600。
- 更新前保留 `state.enc.bak`，临时文件写入后原子替换。缺失密钥时不会覆盖旧数据。
- 关闭应用后备份整个数据目录；恢复时同时恢复密钥和密文。
- 删除当前笔记不会擦除其他备份；本机完整目录的读取权限也意味着能恢复其中的密文，不是跨用户保险箱。
- QQ 默认断开；保存设置会断开 QQ 并取消尚未投递的旧回复，需重新连接。模型厂商登录状态保留。
- 不向浏览器回传已保存的密钥，不公开通用 `/v1` 反代端口，不记录聊天正文到诊断日志。
- 当前仅文字聊天，没有 shell、工具执行、图片 / 语音 / 文件理解。

## 验证范围

独立版 76 项自动化测试：配置加密、模型路由、账号授权协议、签到幂等、社交决策、记忆、OneBot 和官方 QQ SDK 的 WebSocket / Webhook / 扫码生命周期。

TRAE 已有真实登录、目录、聊天与当天签到联调记录；其他厂商主要是协议替身覆盖。官方 QQ 已实际获取绑定二维码，机器人真实收发与 NapCat 实机接入仍待用户账号联调。测试替身结果不等于线上账号连通。
