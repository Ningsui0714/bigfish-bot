把不同厂商账号里的免费额度、签到积分和活动权益，放进同一个本地聊天入口。登录账号、选好模型，再把大肥鱼接进 QQ。

她会接话、会记事，也会在没必要插嘴时安静。想换个性格，就切换人格；每个人格都有自己的记忆，不用重新配置模型和 QQ。

## 这只鱼能做什么？

| 能力 | 用起来是什么样 |
| --- | --- |
| **一键白嫖** | 集中管理厂商账号，使用账号已有的免费额度与活动权益，省掉来回打开客户端的麻烦。 |
| **每日领鱼粮** | 一键签到已登录账号；打开自动签到后，应用按天检查、领取和刷新余额。 |
| **同款模型只选一次** | 跨厂商归并相同型号，保留各渠道真实模型 ID，按可用渠道调用。 |
| **像群友一样接话** | @、叫名、话题、对话延续分别判断，配合冷却、静音和复读过滤。 |
| **人格各有自己的记忆** | 新建、选择、另存模板、删除；人设、节奏、长期笔记和短期对话分别保存。 |
| **QQ 在一个页面接好** | 官方 Bot 扫码，或使用 NapCat 原生安装、后台托管和页面内扫码。 |
| **知道哪一步出了问题** | 直接查看消息权限、接话决策、模型推理、消息送达与历史保存的实际链路。 |

## 快速开始

准备 **Node.js ≥ 22.19** 和 npm：

```sh
git clone https://github.com/Ningsui0714/bigfish-bot.git
cd bigfish-bot
npm --prefix standalone ci
npm run build
npm start
```

打开 [本地控制台](http://127.0.0.1:3210/)。主应用独立运行，不需要 DSH，也不要求安装 Docker。

1. **模型账号**：选择厂商，登录并获取模型列表，选好统一聊天模型后保存。
2. **互动实验室**：先聊两句，测试模型和人设。这里只在本地聊天，不会发到 QQ。
3. **QQ 接入**：选择官方 Bot 或 NapCat，完成扫码，设置允许回复的群和联系人。
4. **人格与节奏**：调整性格、记忆和接话方式，保存即生效；不改 QQ 接入配置就不需要重连。

| 渠道 | 厂商 / 项目 |
| --- | --- |
| TRAE | 字节跳动 |
| CodeArts | 华为云 |
| ZCode | 智谱 |
| Cline | Cline Bot Inc. |
| Loomy | 科大讯飞 |
| Raccoon · 小浣熊 | 商汤科技 |
| MiniMax Code | 稀宇科技 |
| Gemini Code Assist | 谷歌 Google |
| Qoder / Qoder 中国版 | 阿里云 |

账号详情跟随下拉框选择，不再把不同厂商的登录信息混着展示。也可以在高级配置中填写自己的兼容 API。

同款模型合成一个选项。例如 `DeepSeek V4.1 Flash` 及其同版本日期别名会归并展示，实际请求仍使用所选渠道的原始 ID。Flash、Pro、不同代际和预览版分开保留；同型号有多个可用渠道时，由路由选择，不用来回改厂商配置。

**每日领鱼粮**集中展示签到进度、结果和余额。打开总开关，再为需要的账号启用“每天自动签到”；应用启动后检查当天状态，跨日继续执行。自动发放的权益、需要在厂商页面完成的交互，也会单独显示。

免费权益来自各账号本身；自填 API 或付费账号按对应套餐使用。**有道龙虾（LobsterAI · 网易有道）因用户反馈封号风险，已从渠道中移除。**

更多配置见 [账号与模型说明](standalone/ACCOUNTS.md)、[自动签到说明](docs/daily-benefits.md)。

## 接入 QQ

| 路径 | 连接方式 |
| --- | --- |
| **官方 QQ Bot** | 用手机 QQ 扫码绑定开放平台机器人，自动保存凭据，通过 WebSocket 连接。 |
| **NapCat · 原生免 Docker** | 下载对应系统的官方组件，首次安装后在大肥鱼页面扫码。macOS 支持由大肥鱼后台启动、停止托管实例。 |
| **已有 NapCat / Docker** | 已有服务填写 WebUI 地址和管理 Token；Docker 作为可选部署保留。 |

官方 Bot 和 NapCat 是两种 QQ 通道，模型、人设和记忆仍由大肥鱼管理。

在“群聊与私聊白名单”填写允许的会话；私聊还需打开 **启用白名单私聊**。收到消息后，也可以从最近会话中选择“允许此人私聊”。官方 Bot 使用 OpenID，NapCat 使用 QQ 号和群号。

NapCat 原生模式日常不必再打开安装器或终端；首次组件安装和系统授权按页面引导完成。大肥鱼只停止自己托管的实例，已有外部服务照常保留。

详见 [QQ 扫码与 NapCat](standalone/QQ.md)。

## 人格与记忆

默认是原来的大肥鱼：蓝发、鲸尾、抱着饭碗发呆，有点呆萌，也有自己的兴趣。项目不会自动替你生成一堆角色。

在 **人格与节奏** 顶部管理人格和模板：

- **下拉选择**：选择要编辑的人格或模板，保存后启用。
- **新建**：填写名称，使用空白人设，或复制当前设置。
- **另存为模板**：只复制人设与节奏，不复制记忆和对话。
- **删除**：确认后清理所选人格的独立记忆；删除当前项会切换到剩余项，至少保留一个。

**短期对话**默认保留最近 12 轮成功对话，24 小时有效，重启后可以继续聊；轮数和保留时间按人格设置。**长期笔记**由你明确说“记住”后保存，可以查看和删除。

记忆同时按人格、渠道、会话和成员隔离。切换回来，还是那个人格自己的记录；改显示名称不会丢记忆。

```text
大肥鱼，电影结尾你怎么看？
大肥鱼，安静
大肥鱼，可以说话了
大肥鱼，记住：我喜欢乌龙茶
大肥鱼，你记得我什么
大肥鱼，忘记我
```

本地会话命令不调用模型：

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看命令 |
| `/reset` 或 `/new` | 换个新话题，清空自己的短期对话，保留明确记忆 |
| `/memory` | 查看自己在当前人格、当前会话里的笔记 |
| `/status` | 查看当前会话记录状态 |

私聊直接发送；群里使用 `@机器人 /help` 这样的明确唤醒。

详见 [人格与模板管理](docs/personas.md)。

## Agent V2

参考 AstrBot 的分阶段消息管线、会话管理和事件钩子思路，大肥鱼保留自己的 Node.js 实现与账号模型链路。

```text
收到消息 → 权限与去重 → 本地命令 / 接话决策 → 会话排队
        → 人格与上下文 → 模型 → 回复后处理 → 发送 → 加密保存
```

群里不是每条消息都要回：兴趣、冷却、复读、静音和被动回复预算先在本地判断；需要生成时才调用模型。历史只记录成功送达的对话，重置或切换人格会取消尚未送达的旧回复。

在“人格与节奏”查看每轮处理阶段和耗时。开发者可注册命令、模型前后、消息送达钩子，扩展大肥鱼的行为；这是项目自己的 JS 扩展接口。

实现与扩展方式见 [Agent 内核说明](docs/agent-runtime.md)。

## 本地数据与备份

设置、账号凭据、人格和记忆放在 `standalone/data/`，使用 AES-256-GCM 加密，该目录不进入 Git。

备份时一起保留 **`state.enc` 和 `local.key`**；`.bak` 是修改前的加密副本。管理服务默认只监听本机。

```sh
PORT=3212 npm start
BIGFISH_DATA_DIR=/absolute/path/to/bigfish-data npm start
```
